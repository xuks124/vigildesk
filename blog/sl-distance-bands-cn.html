止损设多远？189 笔实盘分桶后：最危险的是「中间带」

VigilDesk 团队 · 2026-10-09 · 阅读约 6 分钟

直觉说法是「止损越近，单笔风险越小」。我们把自己在跑的 MT5 EA 六周账本（2026-08-27 至 10-08，189 笔平仓，含止损距离字段）按止损距离分成四桶，逐桶算了胜率、盈亏合计和平均 R。结论跟直觉对不上：最烧钱的既不是最窄的桶，也不是最宽的桶，而是中间那一带。

先说两个桶的死法，它们是两种完全不同的错误。

窄桶（≤1 点）：止损贴着噪音，8 笔死 7 笔

这一桶 8 笔只有 1 笔盈利，平均 -0.93R——几乎就是「设了必被打」。止损距离小于 1 点时（我们的品种是黄金，点差与正常呼吸都以 0.x 点计），你不是在设止损，是在预约成交。这种单亏的钱不多（合计 -6.34），但它教给你的统计结论是错的：你会以为「这个信号不行」，其实死的是止损宽度，不是信号。

中间带（3-6 点）：问题不是区间，是离场方式

漏水大户是 3-6 这一桶：66 笔亏 -203.72，其中 43 笔亏损单合计 -476.74。按离场原因拆开后，出现全账本最大的一组对比：

3-6 点区间内：
  纯价格止损离场（server_sl）  52 笔  10 胜  合计 -287.64
  时间止损离场（time_stop）    11 笔  10 胜  合计 +70.78

同一个价格区间，换个离场方式，差距 358。更扎眼的是胜率：价格止损离场胜率 19%，时间止损离场胜率 91%。翻译过来：3-6 点的止损在这个品种的日内波动里，恰好落在「会被毛刺扫掉、又不够容纳趋势展开」的尴尬宽度上——扫掉之后价格回头，你已经不在场。而让订单多活一段时间（时间止损）反而等到了要走的那段。对比之下，>6 点那一桶里价格止损离场 34 笔合计 -1.85，基本打平——同样叫「价格止损」，宽度不同，命运两样。

宽桶（>6 点）：全账本前五大盈利单全在这里——但固定手数让它变成另一颗雷

账本里最大的五笔盈利：+88.47（止损距 14.74）、+67.07（11.18）、+59.55（8.30）、+46.08（7.68）、+38.34（6.43）。没有一笔出自 6 点以内。如果你的复盘口径是「统计止损单亏损」，你会得出「宽止损更危险」——因为这一桶确实出现了全账本单笔最大亏损 -42.68。但那不是宽止损的错：我们那几周手数是固定的（各桶平均手数都是 0.027-0.028，说明系统根本没按止损距离调仓）。固定手数下，风险 = 手数 × 止损距离，止损放宽一倍，单笔风险就静默翻倍。-42.68 与中间带最差的 -17.52，差的只是数学，不是运气。

三个可直接照做的结论

  1. 先归一手数，再谈止损宽窄。每笔风险固定为余额的固定金额 R元，手数 = R元 ÷ (止损距离 × 每点价值)。归一之后，四桶的对比才在比「信号与离场」，而不是比「谁的仓位大」。
  2. 中间带禁止裸挂价格止损。3-6 点区间要么收紧到有事件依据的窄位（回到「贴噪音」之前先确认噪音边界），要么保留宽度但配一个时间止损兜底——我们自己的数据是这一条值 358。
  3. 分桶复盘，而不是总账复盘。总账 -235.20 只告诉你「最近六周不好过」；分桶之后才知道钱从哪一类单子里漏出去。样本再小，分桶口径也比总账口径早很多步告诉你该修什么。

十分钟自查脚本（按你自己的账本结构改字段名即可）：

import json, collections
rows = [json.loads(l) for l in open('trade_ledger.jsonl', encoding='utf-8')]
opens = {r['ticket']: r for r in rows if r['event'] == 'open'}
b = collections.defaultdict(lambda: [0, 0, 0.0])
for r in rows:
    if r['event'] != 'close':
        continue
    o = opens.get(r['ticket'])
    if not o or 'sl_dist' not in o:
        continue
    d = o['sl_dist']
    k = '<=1' if d <= 1 else '1-3' if d <= 3 else '3-6' if d <= 6 else '>6'
    b[k][0] += 1
    b[k][1] += r['pnl'] > 0
    b[k][2] += r['pnl']
for k in ('<=1', '1-3', '3-6', '>6'):
    print(k, 'n=%d win=%d sum=%.2f' % tuple(b[k]))

诚实声明：一个 EA、一个品种、六周、189 笔——样本不大，别把「宽止损更好」当结论抄走。这组数据真正支持的只有一句话：止损距离不是风险，手数 × 止损距离才是；而中间带的止损，值得你单独盯一遍。
